# Mobile QA & Exploratory Testing Portfolio

## 📌 Project Overview
This repository contains professional documentation for **Mobile QA and Exploratory Testing** practices. It demonstrates advanced analytical skills, session-based test management (SBTM), heuristics application in responsive viewports, and standardized bug reporting for mobile web applications.

## 📁 Repository Contents
* **`bug_report_template.md`**: A standardized, industry-grade bug reporting template detailing metadata, steps to reproduce, expected vs. actual results, and evidence attachments.
* **`exploratory_session_notes.md`**: Structured notes from a mobile exploratory testing session, incorporating touring heuristics, network throttling simulation, console monitoring, and layout shift (CLS) risk analysis.

## 🛠️ Skills & Techniques Demonstrated
* Session-Based Test Management (SBTM)
* Mobile Web Responsiveness & Viewport Testing
* Heuristic-Based Exploratory Testing
* Defect Lifecycle & Severity/Priority Classification
* Professional Technical Writing in English for Global QA Roles
